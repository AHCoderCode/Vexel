CONTACT & SUPPORT

Contact Vexel AI

Use the public project issue tracker for general product feedback and reproducible bug reports. Before posting, remove personal data, private conversations, passwords, and any API keys.

General questions and bug reports

The Vexel project is maintained in a public GitHub repository. You can report a reproducible issue, describe a feature request, or review existing reports there.

Open Vexel project issues

When reporting a bug, include the browser, the steps that caused the problem, what you expected, what happened instead, and any relevant error message. Do not include account credentials, session tokens, private chat contents, or personal information. Public issues may be visible to anyone.

Privacy and account requests

Do not post a private account, chat-history, or data-deletion request in a public issue. The project currently does not publish a dedicated private support email on this page. The service operator should add a monitored private contact channel and document the account-data deletion process before treating this support page as complete.
